รายละเอียดงาน

1.งานด้าน New Model / New Product
2.จัดทำและดูแลเอกสารที่เกี่ยวข้องกับงานวิศวกรรม
3.ประสานงานด้านการพัฒนาผลิตภัณฑ์และกระบวนการ
4.จัดทำและติดตามเอกสาร PPAP
5.สนับสนุนงานระบบ ISO 9001 / IATF 16949
6.งานอื่น ๆ ที่เกี่ยวข้องกับฝ่าย New Model

คุณสมบัติ

1.อายุ 25–35 ปี
2.วุฒิการศึกษา ปวส. ขึ้นไป สาขาที่เกี่ยวข้องกับวิศวกรรม / เทคโนโลยีการผลิต
3.มีประสบการณ์ทำงานอย่างน้อย 1 ปี
4.สามารถใช้ AutoCAD 2D/3D ได้
5.มีประสบการณ์ด้าน PPAP, ISO 9001, IATF 16949 และ Core Tools จะพิจารณาเป็นพิเศษ
6.มีความรู้ด้านฉีดพลาสติก จะพิจารณาเป็นพิเศษ
7.สามารถใช้ Microsoft Office ได้
8.สามารถสื่อสารภาษาอังกฤษได้
9.มีความรับผิดชอบ และสามารถทำงานร่วมกับผู้อื่นได้ดี

1.ประกันสังคม
2.ค่าครองชีพ
3.ค่าตำแหน่ง
4.ค่าข้าว
5.ค่าเดินทาง
